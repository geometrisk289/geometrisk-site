Don’t have a link yet? Set one up on Calendly  ›
  1. Create a free account at calendly.com using your work email.
  2. Add an event type — call it something like “Risk consultation — 30 min”. Set the length and the hours you’re available.
  3. Choose how you meet under Location — pick In-person meeting (add your address) or Phone call. That’s the modality clients see.
  4. Copy your event link — it looks like calendly.com/your-name/risk-consultation.
  5. Paste it above and hit Test link to confirm it opens your booking page.

Already use Google Appointment Schedule or Microsoft Bookings? Paste that link instead — any public booking URL works. We recommend Calendly because it’s free and quickest to set up.
